# Saga do Norte (nome provisório)

Projeto da disciplina **Projeto de Jogos Digitais I** — desenvolvimento de um jogo 2D com Unity e C#.

Jogo de estratégia por turnos com conquista de territórios, ambientação viking (inspirado em Vinland Saga, com personagens e enredo originais), estilo pixel art.

## Estrutura do repositório

```
/GDD              -> Game Design Document e versões
/UnityProject      -> Projeto Unity e código C#
/Art
  /ConceptArt      -> Concept arts
  /ModelSheets     -> Model sheets dos personagens
  /Sprites         -> Sprites finais
  /UI              -> Elementos de interface
/Animation         -> Animações
/Audio
  /SFX             -> Efeitos sonoros
  /Music           -> Trilha sonora
/LevelDesign        -> Mapas e planejamento de fases
/QA                -> Registros de playtesting e bugs
```
